# Rock Paper Scissors

A JavaScript-based Rock Paper Scissors game built as part of [The Odin Project](https://www.theodinproject.com/).

## Project Status

🚧 In Progress

## Current Features

- [x] Human player choice using browser prompt
- [x] Random computer choice
- [x] Single-round winner determination
- [ ] Score tracking
- [ ] Five-round game
- [ ] Final winner announcement
- [ ] Input validation and edge-case handling

## Technologies Used

- HTML
- JavaScript
- Git
- GitHub

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Open the browser console to see the game results.
